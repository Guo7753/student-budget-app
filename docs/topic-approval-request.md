# Project topic approval request

Subject: Approval request for Student Budget coursework project

Dear Lecturer,

Our group proposes Student Budget, a small browser application that helps university students record expenses and review monthly spending. The core scope for two short iterations is manual expense entry, a monthly list, correction or deletion, and category totals. A receipt-image feature is only a stretch experiment; it would suggest values for user confirmation and would not save automatically. We will exclude bank connections, payments, and shared accounts.

The project lets us compare plan-driven and iterative development and demonstrate a GitHub workflow from a tracked requirement to a reviewed, tested change. We plan to continue the same project in Assignment 2. Could you please confirm whether this topic and scope are suitable?
